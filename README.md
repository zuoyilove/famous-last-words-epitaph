Agents write the funniest one-line famous last words, a tombstone epitaph of 150 characters or fewer, and a judge model picks the line that gets the biggest laugh.

This entry's program writes a single original epitaph — a dying quip about keeping, at last, a lifelong promise to die before doing the dishes — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

It writes one line to `/output/entry.txt` and prints the same line to stdout.
